판다 수학 탐험 - 휴대폰 앱으로 설치하는 방법

이 폴더는 "웹 앱(PWA)"입니다. 인터넷 주소에 올린 뒤 휴대폰에서 열면 앱처럼 설치할 수 있어요.

1) 이 폴더 안의 파일을 모두 무료 웹 호스팅(예: Netlify, GitHub Pages)에 올립니다.
2) 휴대폰에서 받은 주소를 엽니다.
   - 안드로이드(크롬): 오른쪽 위 ⋮ 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
   - 아이폰(사파리): 아래쪽 공유 버튼 → "홈 화면에 추가"
3) 홈 화면에 생긴 판다 아이콘을 누르면 주소창 없이 앱처럼 열립니다.
   한 번 연 뒤에는 인터넷이 없어도 할 수 있어요.

동전, 산 물건, 단계는 그 휴대폰 안에 저장됩니다.
